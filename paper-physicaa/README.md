# Physica A submission package

Target: *Physica A: Statistical Mechanics and its Applications* (Elsevier),
Editorial Manager `physa`. Class `elsarticle`, options `preprint,12pt`,
bibliography style `elsarticle-num-names`.

This directory is **generated**. `main.tex`, `supplementary.tex` and the
`table_*_generated.tex` files are written by `assemble.py` from the
venue-neutral master `../paper/main.tex`; editing them directly is lost on the
next build. Edit the master, or the venue-specific parts listed below, and
rebuild.

## Build

```
python build.py
```

Runs the whole chain in the only order that produces a correct document:
assemble, then `pdflatex` / `bibtex` / `pdflatex` twice for `main`, then the
same for `supplementary` (which needs `main.aux` for `xr`), then `highlights`,
then `package_source.py`. It reports pages, overfull boxes and unresolved
references per document and refuses to package a `main.bbl` older than
`main.tex`.

`highlights.docx`, `declaration_of_interest.docx` and `cover_letter.docx` are
generated by `make_submission_files.py`, which `build.py` runs last. Editing
them by hand is lost on the next build; edit `highlights.tex`,
`declaration_of_interest.txt` or `cover_letter.md` instead.

Everything else in the manuscript comes verbatim from `../paper/main.tex`.

## What `assemble.py` checks

The script fails rather than producing a subtly wrong package. It asserts:

- the Introduction is 900 to 1500 prose words and keeps `\label{sec:intro}`;
- Related work is 550 to 900 prose words, opens as a subsection, keeps its
  conceptual spine of 20 required citations, includes the three Physica A
  references, and no longer cites the three CSF courtesy references;
- the abstract is 150 to 250 words and there are at most six keywords;
- three to five highlights, each at most 85 characters;
- no em-dash anywhere in either assembled document;
- every substitution anchor occurs exactly once, so a reworded master fails
  loudly instead of silently skipping an edit;
- every `\ref` in the main text that points into the supplement is worded
  "Supplementary ..." rather than bare, since `xr` fixes the number but
  nothing fixes the wording;
- no label treated as moved is still defined in the main text;
- the figures staged here are exactly those `../results/figures/` renders.

## Structure

Seven top-level sections in the master become five here:

1. Introduction (1.1 Related work)
2. Model
3. Results
4. Discussion (4.1 Limitations)
5. Conclusion

Moved to `supplementary.pdf`, in this order: threshold sweeps (S1), the
nucleation result (S2), the ablation scan (S3), screening and fining channels
(S4), provider-scoped credentials (S5), liability and robustness (S6) and all
analytical derivations (S7).

The main text still refers to S1, S2, S4, S6, S6.1 and S7 by name. Those
numbers are resolved by `xr` against `supplementary.aux`, not typed, so
reordering the supplement in `assemble.py` cannot leave the main text pointing
at the wrong section. `build.py` interleaves the LaTeX passes for that reason:
main writes the labels the supplement needs, the supplement writes the labels
main needs, and each has to run again to read the other's. Compiling one
document to completion before starting the other leaves the first full of `??`.

Unlike `../paper-csf/`, the multistability section is kept whole. It carries
Theorem 1 (face reduction), the regime map over the (sigma, r) plane and the
basin-measure analysis. `paper-csf/` contains no `thm:face` at all: the theorem
postdates that submission.
